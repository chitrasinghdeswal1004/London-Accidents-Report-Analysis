🚗 London Accidents Report Analysis

📌 Project Overview
An analysis of London accident reports using Tableau Public, focusing on environmental factors such as weather and time. Future updates will explore additional aspects and insights.

🔍 Key Insights
Impact of weather conditions on accident rates
Influence of time of day on accident frequency
Patterns in accident severity and locations

🔧 Tools & Technologies
Tableau Public – Interactive data visualization
Excel/CSV – Data format for analysis
